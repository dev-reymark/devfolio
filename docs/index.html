Step-by-step

Deploy without touching the terminal

1

Fork & Deploy

Click the Deploy button at the top of the repository. Vercel will ask you to log in with GitHub and will automatically clone this codebase into your account and deploy it.

Deploy with Vercel
2

Update Configuration

Navigate to your newly created GitHub repository, open the data/portfolio.ts file, and click the Edit (pencil) icon to add your own data.

export const portfolioData = {
  name: "Your Name",
  jobTitle: "Your Job Title",
  professionalSummary: "A brief bio about yourself...",
  email: "your.email@example.com",
  social: {
    github: "https://github.com/yourusername",
    linkedin: "https://linkedin.com/in/yourusername"
  },
  // Add your experiences, education, and projects below!
};
3

Commit & Watch

Once you commit your changes in GitHub, Vercel will instantly detect the update and push your new information live to the world!

Automated Pipeline Active

No need to manually trigger builds. Every save to the main branch updates your site within seconds.

For Developers (Local Setup)

Running Locally

If you want to clone the project and run it on your local machine to make architectural changes, you will need Node.js installed.

# 1. Clone the repository
git clone https://github.com/your-username/devfolio.git

# 2. Navigate into the directory
cd devfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

# 5. Open http://localhost:3000 in your browser

Adding your PDF Resume

The "Download Resume" button works by linking to a file in the public/ folder.

  • Simply drop your actual PDF resume into the public/ folder.
  • Ensure the file is named exactly resume.pdf.
  • Commit and push the file to GitHub.
